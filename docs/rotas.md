## Detalhes:

- Prefix: **/api/v1**

## EndPoints

- **Default**
  - **GET 📤 /** Retorna a mensagem "acesse /api para verificar a documentação"

- **Member**
  - **POST 📥 /members:** Cria uma novo membro
  - **GET 📤 /members** Lista todas membros
  - **GET 📤 /members/:id** Busca um membro através de seu ID
  - **PUT 🔄 /members/:id** Atualiza propriedades de um membro através do ID e passando novos dados pelo body
  - **DELETE 🗑 /members/:id** Deleta um membro

- **Project**
  - **POST 📥 /projects:** Cria uma novo projeto
  - **GET 📤 /projects** Lista todos projetos
  - **GET 📤 /projects/:id** Busca um projeto através de seu ID
  - **PUT 🔄 /projects/:id** Atualiza propriedades de um projeto através do ID e passando novos dados pelo body
  - **DELETE 🗑 /projects/:id** Deleta um projeto

- **Skill**
  - **POST 📥 /skill:** Cria uma nova Skill
  - **GET 📤 /skill** Lista todas skills
  - **GET 📤 /skill/:id** Busca uma skill através de seu ID
  - **PUT 🔄 /skill/:id** Atualiza propriedades de uma skill através do ID e passando novos dados pelo body
  - **DELETE 🗑 /skill/:id** Deleta uma skill

- **Soft Skill**
  - **POST 📥 /soft-skill:** Cria uma nova Soft Skill
  - **GET 📤  /soft-skill** Lista todas Soft Skills
  - **GET 📤 /soft-skill/:id** Busca uma Soft Skill através de seu ID
  - **PUT 🔄 /soft-skill/:id** Atualiza propriedades de uma Soft Skill através do ID e passando novos dados pelo body
  - **DELETE 🗑 /soft-skill/:id** Deleta uma Soft Skill
